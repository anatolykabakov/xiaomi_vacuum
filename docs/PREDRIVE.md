# Чек-лист перед запуском

 Пишется до запуска,
потому что критерий, придуманный после взгляда на лог, — не критерий.

## Перед стартом

1. **Робот на полу, батарея > 30 %.** На базе он не поедет (активный режим сдаёт его с контактов сам).
2. **Место на корне робота.**
   ```bash
   ssh root@192.168.0.137 'df -h /; ls -la /opt/xiaomi_robot*.log'
   ```
   Если `Avail` близко к нулю — удалить ротированные логи `/opt/xiaomi_robot.[123].log`.
   Иначе приложение умрёт на ротации (см. `PLATFORM.md`).
3. **Бинарь актуален.** `scripts/build_arm.sh --deploy` кладёт его в `/mnt/data/xiaomi_robot`
   (в `/opt` — симлинк).
4. **Стек не запущен от прошлого раза.**
   ```bash
   scripts/start.sh status 192.168.0.137
   ```

## Запуск

```bash
scripts/start.sh start 192.168.0.137
```

Ожидаемый статус через несколько секунд: RoboController up, keepalive up, xiaomi_robot up, робот
`manual_control`, лидар `count=360`.

## Что считать «поехало»

| проверка | критерий | где смотреть |
|---|---|---|
| лидар стримит | `LASER: … 360 …` с ненулевыми дальностями | `/opt/xiaomi_robot.log` |
| поза живая | `POSE:` меняется при покачивании робота рукой | лог |
| карта строится | `MAP:` раз в секунду, на телефоне видны стены | лог, ZMQ 9091 |
| безопасность | нажать бампер → `SAFETY: … STOP bumper` в логе, отпустить → снимается | лог |
| цель принимается | отправить `Goal` → `PLANNER: … state=3` (following), `TRAJ: … points=N` | лог |

Для автономного движения по траектории RoboController должен быть **остановлен после** активации
(`PLATFORM.md`): иначе он перебьёт `cmd_vel`. Ожидать скорости 2–3 см/с.

## Остановить

```bash
scripts/start.sh stop 192.168.0.137
```

Снимает ручной режим, отправляет робота на базу пока RoboController жив, гасит всё. Если робот
остался `idle` вне базы — поставить руками; автовозврат далеко от дока ненадёжен.

## Что записать после

Куда доехал относительно цели (по `POSE`), сколько раз срабатывал `SAFETY`, были ли `blocked`
у планировщика и на какой карте. Это входные данные для настройки `plan_*` и `ctrl_*`.
